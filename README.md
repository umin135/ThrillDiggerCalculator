# SkyDigger

**젤다의 전설 스카이워드 소드 HD**의 미니게임 **두근두근 루피찾기**를 위한 확률 계산기입니다.

게임에서 판 칸의 결과(루피 색, 도둑루피)를 입력하면, 남은 칸마다 폭탄이 나올 확률과 그 칸을 팠을 때의 기대값을 보여 주고 가장 좋은 칸을 추천합니다.

## 특징

- **정확한 확률**: 단서와 모순되지 않는 꽝(폭탄·도둑루피) 배치를 근사 없이 모두 셉니다. 경우의 수 가중치도 반영합니다.
- **빠른 계산**: 열 단위 sweep DP를 써서 상급(8×5)에서도 한 번 계산하는 데 수 ms면 됩니다. 계산은 Web Worker에서 돌아서 화면이 멈추지 않습니다.
- **폭탄/도둑루피 구분**: 꽝 확률과 실제 폭탄 확률을 따로 보여 줍니다.
- **루피 색 분포와 기대값**: 칸을 누르면 어떤 색 루피가 나올지 확률과 기대 수익이 나옵니다.
- **연습 플레이**: 무작위 판에서 직접 파 보고, 확률 보기·추천 칸 파기로 연습할 수 있습니다. 난이도별 기록이 쌓입니다.
- **자동 시뮬레이션**: 추천대로만 파는 방식으로 수천 판을 돌려 승률과 평균 손익을 보여 줍니다.
- 되돌리기/다시하기, 자동 저장(localStorage), 키보드 입력, 모바일 레이아웃, 다크 모드를 지원합니다.

## 난이도

| 난이도 | 판 | 폭탄 | 도둑루피 | 참가비 |
|---|---|---|---|---|
| 초급 | 5×4 | 4 | 0 | 30 |
| 중급 | 6×5 | 4 | 4 | 50 |
| 상급 | 8×5 | 8 | 8 | 70 |

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 솔버 테스트 (전수 나열 기준값 비교 + 성능)
npm run build    # dist/ 에 정적 파일 생성
```

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 테스트, 빌드, 배포를 순서대로 실행합니다.

1. GitHub 레포에서 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. `main`에 push합니다.

빌드는 상대 경로(`base: './'`)를 쓰므로 레포 이름과 상관없이 동작합니다.

## 구조

```
src/
├─ game/levels.ts      난이도·루피 정의
├─ game/state.ts       판 상태, 되돌리기, 저장, 연습 기록
├─ game/play.ts        연습 플레이 판 생성·파기
├─ game/simulate.ts    추천대로 자동 진행
├─ solver/sweepDp.ts   열 단위 forward/backward DP
├─ solver/analyze.ts   판 → 확률·기대값·추천
├─ solver/worker.ts    Web Worker
├─ solver/client.ts    Worker 호출 (최신 요청만 반영)
├─ ui/                 아이콘, 포맷
└─ main.ts             화면
tests/                 전수 나열 기준값, 성능 테스트
```
